# Compare the Triplets

## Problem
Two players, Alice and Bob, are given three scores each. Compare their scores index by index:
- If Alice's score at an index is greater, she gets 1 point
- If Bob's score at an index is greater, he gets 1 point
- If equal, neither gets a point

Return the final point tally as `[Alice's score, Bob's score]`.

## Example

Input:
```
5 6 7
3 6 10
```

Output:
```
1 1
```

## Complexity
- Time: O(1)
- Space: O(1)
